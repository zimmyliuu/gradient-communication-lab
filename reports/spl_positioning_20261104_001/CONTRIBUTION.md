# SPL 一页贡献说明

日期：2026-11-04。状态：**研究定位交付完成；独立论文贡献尚未确立，G2a 暂缓。** 依据[技术方案顶部修订](../../TECHNICAL_PLAN.md)及[本轮验收意见](../../reviews/gpu_codec_v1_20261104_001_review_and_g2a_plan.md)。以下是一页内容预算的说明稿，尚未进行出版模板排版。

**问题。** 低比特梯度在递归聚合中反复解码、相加和量化。首轮随机共享尺度可能引入组内依赖，下一轮又依赖随机输入的最大值重选尺度。能否在大量随机回放之前，准确预测这**两次连续量化**的终点均方误差？信号处理对象是量化失真及其传播。

**最近工作与排重结论。** [DynamiQ v3](https://arxiv.org/html/2602.08923v3#A2)已有层次量化和拓扑误差分析；[有限精度随机舍入研究](https://arxiv.org/html/2408.03069v3)已有条件偏差及递归求和分析；[Global-QSGD](https://mcanini.github.io/papers/gqsgd.ecai25.pdf)已有量化归约的方差传播理论。因此，发现偏差、累加逐跳误差或完成 GPU ring 均不足以成为本论文贡献。

**唯一保留的待证主张。** 对一个 256 元素层次块，利用共享尺度分支下的条件分布，计算首轮输出坐标与下一轮最大值的联合分布，得到两轮终点误差的精确矩或带明确误差控制的近似，避免枚举所有坐标的联合随机结果。区别必须体现在相关性与尺度重选的可计算联合分析；单跳矩公式不够。当前没有定理或新实验支持该主张，不能宣称已填补文献空白。

**最小充分证据。** 先完成命题、证明和逐式排重；通过后用 CPU 两轮单 chunk 链验证，保留 sink 量化。比较独立边缘近似、均值路径近似及精确小实例；固定 b4/b8，报告误差预测精度和计算代价。明确独立显式阈值的适用域，不外推原相关随机池。G1 与官方 CUDA 算术分别核验；预注册后再测，旧梯度只作开发案例。

**已有基础与限制。** G1 的 2098 条正确性记录通过，局部 CUDA 优化可用；其相对 PyTorch eager 的加速不证明研究新颖性。旧闭环仅证明已有 DQ4 在两个开发种子的适用性。旧随机耦合候选和当前小模型配方上的新方法研发仍保持停止。[证据与来源](EVIDENCE_AND_GATES.md)

**执行决定及停止条件。** 下一工作单只做两轮理论可行性判定；恒等式、事后拟合、指数规模枚举、仅人为退化案例有效、或相比合理近似没有实用价值，任一成立即停止。通过后才启动最小 CPU 验证。N>2 的闭合理论、位宽策略和 G2a–G4 不进入默认任务；论文结构见[四页大纲](PAPER_OUTLINE.md)。本轮没有新增定理、GPU 实验或训练结果。
