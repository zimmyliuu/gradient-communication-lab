## 3. 最重要的算术边界

G1 验证的是 `index_repaired_bf16` 冻结 CPU 适配器的局部 b4/b8 算子，数据实际存储 5/9 位并附尺度。它不是官方 CUDA 内核所有路径的复现。[G1 契约](../../results/gpu_codec_v1/gpu_codec_v1_20261104_001/codec_contract.json)

固定上游 commit 为 `96da2ee480bbfd8e2049de3fbd8595cc9d7a30b8`。官方 [CUDA 算法说明](https://github.com/CharlesHan24/DynamiQ/blob/96da2ee480bbfd8e2049de3fbd8595cc9d7a30b8/cuda_kernels/documentation/scaling_quantization_algorithm.md)明确将 BF16 输入转 float 运算，层次 scale 使用向上取整并以重建尺度归一化；本地 CPU 适配器采用逐步 BF16 和随机 scale 量化。官方[大型仿真](https://github.com/CharlesHan24/DynamiQ/blob/96da2ee480bbfd8e2049de3fbd8595cc9d7a30b8/large_scale_sim/scale_sim.py#L930)也已有 BF16 尺度、递归聚合及经验偏差诊断。不能把本地算术发现推广成官方 CUDA 缺陷；这些差异不推翻 G1 的既定验收。

必须解释选用算术 profile 的实际意义，并核验另一真实算术路径。另一 profile 的尺度若为确定值，模型应正确退化，不要求人为制造共享尺度随机性或凭空要求相同收益。若价值仅存在于人为退化案例，本轮候选停止。最小参考实现的数值核对不能伪装成完整部署性能比较。

## 4. 数学起点与真正待解的问题

固定一个 chunk、N>1 个已预处理 BF16 输入 x_h。令 Q_h 表示同一冻结协议的 encode 后 decode，R 表示 BF16 最近舍入；按路径编号：

\[
z_0=Q_0(x_0),\qquad z_h=Q_h(R(z_{h-1}+x_h)),\quad h=1,\ldots,N-1.
\]

最后一步包含 sink 量化。N=1 单独取恒等入口；AllGather 仅转发最终码流，不增加这里的 Q。此链只表示数值路径，不验证完整 collective。

**该式专指 G1 冻结的 BF16 解码链。** 官方 [fused CUDA 路径](https://github.com/CharlesHan24/DynamiQ/blob/96da2ee480bbfd8e2049de3fbd8595cc9d7a30b8/cuda_kernels/src/srrcomp/eden_utils/csrc/cuda_hierarchical_mee.cu#L656)可先把 packet 解码为 float，再与输入相加，最后舍入 BF16；没有独立的“先将解码值舍入 BF16”步骤。另一 profile 必须从 packet 状态定义自己的转移和解码/加法顺序，不能直接复用上式或 G1 的条件矩。

设 S_h 是预处理 BF16 输入的精确实数和，E_h=z_h-S_h，a_h=R(z_{h-1}+x_h)-(z_{h-1}+x_h)，q_h=Q_h(R(z_{h-1}+x_h))-R(z_{h-1}+x_h)。则 E_h=E_{h-1}+a_h+q_h。以历史生成的 σ-代数 F_{h-1} 为条件，定义 μ_h=E[q_h|F_{h-1}]、Σ_h=Cov(q_h|F_{h-1})，有

\[
\mathbb E[\|E_h\|^2\mid F_{h-1}]
=\|E_{h-1}+a_h+\mu_h\|^2+\operatorname{tr}\Sigma_h.
\]

**这只是已有概率工具给出的恒等式，不是拟投稿定理。** 若输入也随机，应先条件于本次固定输入；期望只对所声明随机律取。原始 FP32 平均值到 BF16 入口的误差另报，不能混进 codec 误差。

真正难点是：下次重选 scale、max 和 LUT 区间依赖随机中间状态，逐跳观察到 μ/Σ 并不能提供运行前的闭合预测。共享 scale 的协方差非对角项不直接进入单跳总 L2 MSE；它们可以影响投影误差，或通过后续非线性影响终点。不能仅画协方差热图就宣称解释了终点 MSE。

为控制工作量，核心命题只取 N=2、L=256、固定 b4/b8：由两份已知输入、码本、阈值精确离散分布及算术规则，计算第二次量化后的偏差与 MSE，证明精确性或显式近似误差界。算法、复杂度和证明目前均未形成；不把该目标称作已实现预测器。

拟研究的具体路径是条件混合：给定首轮某个 group 的 scale 分支 k，坐标输出在独立主阈值假设下条件独立；对第二轮 BF16 加法后绝对值最大值 M，使用 F_M(t)=Σ_k p_k ∏_i F_{i|k}(t)。先将每个坐标边缘混合后再相乘，通常不是同一个分布。这一基本概率公式也不是创新。

给定完整首轮输入时，首轮 top scale 是确定值；独立的各组阈值才能给出组间独立。第二轮 top scale 是随机最大值，会重新耦合各组：应组合目标组联合分布与其余组最大值分布，不能条件于第二轮 top 后仍默认各组独立。N=2 指两次量化（首包与 sink），不是两轮 ReduceScatter 通信。

下一轮误差矩需要坐标与 group max、super-group max 的联合分布，不能只有最大值边缘。拟通过有限支持排序及排除当前坐标的分布乘积计算必要联合量，处理共享尺度、并列最大值和 BF16 阶梯。能否避免随坐标数指数增长、同时保留精度与实用计算成本，是 T0 必须解决的实际技术问题。不能假定首轮输出的均值/方差足以闭合。

候选推导中需要核验的联合量为：

\[
P(Z_i=z,M_g\le t)=\sum_k p_{g,k}P(Z_i=z\mid k)
\mathbf1_{|z|\le t}\prod_{j\ne i}F_{j\mid k}(t).
\]

对该有限支持 CDF 取差分，按实际算术映射成 local scale A_g；再与独立的其余组尺度最大值 U_{-g} 组合，形成第二轮 top，最后对第二轮主码和尺度码分支积分。这是待实现并检验的计算路线，不是本轮已证明的复杂度结果。若存在正概率非法/溢出状态，应明确失败域或处理规则，不能删除后重新归一化。近似剪枝必须约束遗漏概率及误差，不可把启发式点值标为精确矩。

需排除两类循环论证：用该次回放的终点误差拟合预测；用所有随机轨迹的指数枚举后称作低成本预测。极小状态精确枚举可做 oracle，不能充当整个 256 元素问题的计算方法。

阈值律也要单独冻结。G1 显式 BF16 阈值不等于连续均匀变量。主阈值之间、各组尺度阈值之间、主与尺度阈值之间、两次量化之间采用所声明的独立随机变量，才能使用上述条件分解；有限 PRNG 回放只是数值近似，不能以不同种子代替独立性证明。该研究对象不等于原 LCG/复用池路径，不能推广为完整 DynamiQ 理论。这里只分析给定随机律，不重启旧随机耦合优化候选。

## 5. 最小工作单及停止门槛

本节是后续执行设计，本轮未执行。只有前一门槛通过，才开展后一项；不能靠扩大系统来绕过理论失败。

| 门槛 | 最小交付与判断 | 不通过时 |
|---|---|---|
| T0：理论可行性 | 一份短证明稿：两轮精确算子/随机律、可计算联合分布、误差矩、复杂度、非空有效例子和逐式排重。单跳全期望公式及直接代入已有结果不足以通过 | 归档 `stop_no_distinct_claim`；不运行 G2a |
| T1：反例优先 | 极小随机状态的合法块精确 oracle；零输入、同向、近抵消、scale 切换、LUT 边界。预测超出所证明误差界的可复算反例首先判为命题失败 | 修正一次明确假设错误并重新排重；仍无非平凡结果则停止 |
| T2：受控试验 | 先冻结 case 与指标，再执行下述小矩阵；检验预测精度和代价。记录全部 case，不筛选有利种子 | 无信息增益或仅人为退化案例有效则停止，不追加训练寻找正结果 |
| T3：论文证据充分性 | 在未用于构造模型的输入上复核适用域、跨 profile 结论；完成必要消融。若写梯度泛化，需有独立梯度证据 | 收窄主张；收窄后不再有独立意义则不投稿 |

**T2 的最小矩阵草案：** 每个通过 T0 定义的 profile，L=256，N=2，b∈{4,8}，三类信号（同向、可控抵消、尺度跨度），每类两个预先固定的输入种子，共 12 个固定输入配置；每个 128 个随机重复用于 pilot。参数、种子和阈值生成器须在读结果前落盘。先完成 T1 和一组成本试跑；若资源不适合，记录 `resource_incomplete`，不能当作算法失败或删减成有利子集。N=4/8 不属于这次主张的默认网格。

初步科学主指标为终点 MSE 预测误差及计算代价。精确小状态实例须满足已声明数值容差；Monte Carlo 误差区间只用于数值相容性检验，不能代替 T0 的证明。比较两个合理近似：匹配坐标边缘而忽略共享依赖；用首轮均值路径重选下一轮尺度。适用的既有理论只按其保证类型比较，不以点预测评分惩罚有效上界。

这里总二阶误差 M2=E||E_1||²，逐元素 MSE=M2/L。跨输入比较用 A=||x_0||²+||x_1||² 归一化总误差及其预测误差，不以可能近零的最终和范数作唯一分母；A=0 时只报绝对误差并单列零输入测试。

建议预先采用实用性门槛：在共享尺度有随机性的预定 profile 上，至少两类信号的中位绝对预测误差不超过上述较好近似的一半，且差距大于参考估计的不确定性；完整报告第三类和全部失败 case。另一真实 profile 应有正确退化与数值核验。计算代价需优于达到同等误差精度的独立回放，否则最多是 oracle；不以 128 次 pilot 直接宣布正式速度优势。该门槛是本项目选题标准，不是学界标准，也不是已观测结果。

该中位数按每类 b4/b8×两个输入种子的四个配置等权计算，并单独列出两种位宽，禁止按元素数或重复数加权。绝对预测误差指 |预测 M2−参考 M2|/A，真实 M2=0 不再另除以 M2；若两个简化基线已精确，该 case 不计为本模型的改善。正式成本协议还须在正式数据前指定置信水平（计划 95%）、可证明/经核验的区间方法、有限误差目标与最大重复预算；所有预处理、分布构造和存储均计入总时间/内存。当前没有用未冻结的成本口径宣布任何收益。

一次 pilot 只决定是否继续，不作为论文最终重复数。正式数值精度目标、重复数与数据角色在 pilot 后、正式数据前另行冻结；pilot 数据全部标为开发集。有限精度、高精度和去 scale 量化的算术消融用不同方法 ID，不混入 G1 同语义性能对比。

若后来添加优化算法，必须另立主张并按实际字节预算比较强基线；当前大纲没有该算法。对本地格式，L 为 256 倍数时单次包大小为 L(b+1)/8+L/16+2L/256 字节；sink 再量化不是额外网络发送。不得把名义 b 当成实际码流位数。

## 7. G2a 的裁剪决定

当前研究问题首先需要单 chunk 数值链。可复用原 CPU encode/decode，不需要 GPU 消息队列、全 rank ownership 测试、AllGather 路由实现或完整工程矩阵。若将来主张涉及 collective 正确性，再裁剪 G2a；若涉及网络性能，再获取真实通信证据。

**本轮结束状态：定位材料已交付，理论可行性仍待验证；没有新增实验或可投稿结论。** 后续最小动作是 T0，不能把本报告当成启动完整 G2a 的批准。
