**明确建议：不按当前主张进入以 SPL 投稿为目的的实验阶段。** 数学可计算性成立，但当前算法主要是成熟精确推断方法对特定量化器的应用；尚未形成足够明确的新增算法优势或实际设计结论。当前投稿候选在此停止，已有工程资产保留。这是对现有主张和投入顺序的判断，不是证明所有两轮量化分析都没有发表可能。

## 2 为什么数学可行仍不建议进入实验

第一，**避免指数枚举并不是这里独有的新方法**。将共享尺度作为隐变量，条件于它后乘坐标 CDF，再消去最大值和其他组，正是利用因子分解改变求和次序的精确变量消元。经典 sum-product 工作已经系统阐述这种计算方式。[Kschischang 等，2001](https://www.isiweb.ee.ethz.ch/papers/arch/aloe-2001-1.pdf)

第二，**当前还缺少相对这个强基线的区别**。上一版只列出了独立边缘近似、均值路径近似、精确枚举与 Monte Carlo，这对论文定位不够。必须加入“按同一因子结构做常规精确变量消元”的比较；当前推导出的算法基本就是它，不能通过遗漏该基线制造新算法优势。

第三，**精确性目前没有转化为清楚的使用理由**。算法可作为离线参考，但它需要两个完整输入和明确随机律，不是通信执行前无额外成本的在线预测器。最直接计算在 L=256 的保守上界约为 3355 万个联合状态、1.34 亿个局部分支项；实际退化与缓存会减少成本，这些数字不能用于断言真实耗时。不过，本轮也没有证明同精度下优于回放。不能把“多项式”直接写成“低成本”。

第四，**已找到的差异尚不足以形成应用结论**。手算见证确实证明共享依赖经过尺度重选会改变终点 MSE，但其价值是验证建模必要性；它没有说明典型梯度需要这样精细的预测。BF16 在部分尺度区间使尺度码完全确定，官方 fused CUDA 的尺度规则也不同，适用价值不能由本地一个反例普遍推出。

SPL 要求相对最接近工作的明确区别；已知理论和算法在已知场景中的直接组合可能被认定新颖性有限。这个要求不是“必须发明新概率原理”，但本候选目前还没有足够的专门算法改进、重要新结论或实证发现来弥补上述缺口。[SPL 作者指南](https://signalprocessingsociety.org/publications-resources/ieee-signal-processing-letters/information-authors-spl)

因此，本轮的停止理由是**现有独立贡献和预期用途不足以支持继续投入**，不是“已有某篇论文已经逐字解决本题”，也不是“本机算力不够”。文献检索没有证明完全重复，数学上也没有证明未来不可能出现更好的方法。

## 4 此前几次实验是否有用

**有用，尤其是已经完成的 CUDA 编解码与逻辑聚合验证。它们主要是工程成果和可信参照，不是这项新理论的验证结果。**

| 交付 | 已经留下的资产 | 对当前 T0 的实际作用 |
|---|---|---|
| [G0 算术与环境核验](../../reviews/gpu_codec_v1_20261101_001_review.md) | 明确 5/9 位实际码流、逐步 BF16 舍入、LUT、阈值和非法状态；识别构建问题 | **直接有用。** 理论必须分析真实算子，本次反例和分支公式就依赖这些精确规则 |
| [G1a PyTorch CUDA 参照](../../reviews/gpu_codec_v1_20261101_002_review_and_g1b_plan.md) | CPU/GPU 码流及输出一致性、可比较基线和输入夹具 | **后续验证可复用。** 纯数学推导不需要运行该 GPU 基线 |
| [完整 G1 自定义 CUDA codec](../../reviews/gpu_codec_v1_20261104_001_review_and_g2a_plan.md) | 紧凑真实打包、保持算术语义的优化内核、受控计时与 trace | **现成工程成果。** 可用于未来独立需要的大量回放；不能拿 codec 加速代替预测器成本优势 |
| [G2a 逻辑 ring](../../reviews/logical_ring_v1_20261104_001_review.md) | 逐跳数值、sink 再编码、AG 转发、包所有权、全 rank 一致性与字节账本 | **间接有用。** 它确认协议接入语义，但完整消息队列和路由不是两轮 T0 的必要前置 |

完整 G1 的代表性实测是：8 MiB BF16 输入、预分配 trusted roundtrip，在本机相对同轮重测 PyTorch eager 基线，b4/b8 配对收益中位数约为 **36.44×/39.41×**；已测 trace 的 roundtrip 从 52 个 kernel 降为 2 个。这里的 b4/b8 主码实际存储为 5/9 位。这些是可展示的实现优化结果，不能写成领先其他成熟 codec、AllReduce 加速或大模型训练加速。

G2a 的 174 个 collective、4741 条正确性记录支撑工程验收；六个真实 collective 来自三个开发快照。它们不是独立训练次数，也不能支持当前预测器的泛化结论。其单 GPU 逻辑通信不等于物理多卡网络测量。

更早的[随机耦合候选报告](../../../spl_model_communication/reports/project_conclusion_report.md)有停止无效路线的价值；[基线闭环报告](../../../spl_model_communication/reports/baseline_closed_loop_v1_completion.md)说明已有 DQ4 在两个开发种子上达到冻结质量目标时，累计逻辑发送字节比 BF16 少约 64.96% 和 66.83%。这是已有方法在指定配方的结果，不支持当前新理论，也不是实测训练加速。

**对投入顺序的评价：** 从“做一个通信与 AI 系统工程项目”看，G1 和 G2a 有明确价值；从“尽快判断这篇窄范围 SPL 候选是否值得做”看，完整 G2a 超出了必要工作量，T0 本可以先于它完成。不能因为这些工作有工程价值，就反过来说它们全是论文研究必需的；也不能因为当前候选停止，就把已验证的工程成果视为无效。

## 5 结束状态与保留方式

1. 当前“两轮精确矩预测”候选不进入新的投稿实验阶段；G2b、G3、G4 和训练继续不自动启动。
2. 保存本报告、理论推导、源码契约和现有结果。CPU 参照、CUDA codec 与逻辑 ring 的工程验收仍然有效，不需要重跑来证明已有投入有价值。
3. 履历可以聚焦低比特 CUDA 编解码、数值一致性、内核优化与集体通信协议验证；明确“单 GPU 逻辑 ring”和比较基线即可。现有包仍有绝对路径及复现入口限制，不称为异机一键复现。
4. 只有出现独立的新依据，例如相对常规变量消元的可证明降本，或真实使用中已观察到需要这种预测解决的问题，才重新评估这一候选；不为寻找正结果而默认追加扫描。

本轮实现了“先用理论判断，避免不必要实验”的目标。停止的是当前投稿主张的继续投入，不是撤销此前的工程成果。
